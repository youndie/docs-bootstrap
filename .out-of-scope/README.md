# Deliberately not done

One file per thing this repository was asked for, considered, and declined — with the reason, and
with what would reopen it.

It exists because a rejected decision does not stay rejected on its own. Six months later the same
idea arrives looking new, the argument is had again from memory, and memory keeps the conclusion
while losing the evidence. A "no" with its reasoning attached is cheaper to re-read than to
re-derive.

What does **not** belong here: anything that already has a home. The rules the checks refuse to
enforce are in [SPEC.md](../SPEC.md) §7 and in the scripts' own docstrings; the process steps left
out on purpose are at the end of [WORKFLOW.md](../WORKFLOW.md). Copying them here would be the
duplication this whole format argues against. What lands here is the decision with no other home:
questions about the repository itself.
